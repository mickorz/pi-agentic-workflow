## 二、脚本与公共能力

- `collect_common.py`：chrome-use 封装（open/eval，输出解析兼容 `{"success","value"}` 包装与裸 JSON 行两种格式——实测两种都会出现）；**浏览器全局互斥锁**（`/tmp/piwf-chrome-collect.lock`，open(wx) 原子占位 + 30min 陈锁接管，方案 V2 P1 落地；生图侧接入登记为 T2 事项）；统一样本骨架（platform/url/title/author/collected_at/collection_method/metrics）
- `xhs_collect.py`：search（搜索页卡片，note_id 去重、author 剥时间噪声、like 仅取含数字值）+ note（详情页）；登录判定宽容式（登录墙=真未登录；头像选择器随页面版本漂移，不作硬依据）
- `mp_collect.py`：search（搜狗列表 + 同源 fetch `/link` 分段拼真实 URL——`url += '…'` 防抓拼装法脚本化）+ article（`#activity-name/#js_name/#js_content` 全字段）；账号/日期用 innerText+尾部时间正则分离（`.s2` 会命中脚本文本，勿用 textContent 直取）
- `dy_collect.py`：video（`[data-e2e]` 指标收集 + on_video_page 判定）+ search（通用引擎 `site:douyin.com` 发现，bing 失败回落 ddg）

## 三、失败模式登记（exit 1 + error 原因）

| 模式 | 判定 | 处置 |
|---|---|---|
| chrome-use 缺失/relay 断 | 子进程非零/超时 | error 原文透传；对应 V2 降级矩阵"预检失败" |
| 小红书登录墙 | `.login-modal` 等选择器命中 | 报"需用户 Chrome 登录态"（Chrome 关闭场景） |
| 小红书无卡片且无头像 | 双空 | 报疑似未登录（区分于"关键词无结果"） |
| 搜狗验证码 | `#seccodeImage` 命中 | 报"稍后重试或换关键词"（真实 Chrome 偶发） |
| 公众号跳转拼不出 | fragments 拼后非 http | search 仍出列表（sogou_link=true 标注），article 步骤降级 |
| 抖音下架/风控 | 未停在 /video/ 路径 | 报"疑似下架跳首页"（本次 7705269715614125339 实测即此模式） |
| 浏览器被占用 | 锁 open(wx) FileExistsError 且未陈旧 | 报占用时长；防多任务抢同一 Chrome |

## 四、T0 期间踩坑（已修）

1. chrome-use eval 输出两种格式混出（带 `success/value` 包装 vs 裸 JSON 行），解析需两者兼容
2. 小红书搜索页与 explore 页 DOM 选择器不一致（头像/标题类名随页面版本漂移）→ 采集器选择器一律容忍式 + 多候选
3. 搜狗 `.s-p` 里 `.s2` textContent 会取到 script 文本（"document.wri…"）→ 必须用 innerText
