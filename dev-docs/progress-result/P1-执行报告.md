## 关键决策记录

1. **workflow() 路径解析**：父脚本目录优先、cwd 次之（CLI 经 scriptPath 选项传入根脚本位置）——修复 `run examples/nested.js` 场景；与参考实现的差异已记录 compatibility.md。
2. **fallback 全候选耗尽语义**：返回 null 且 run 正常结束（fallback 是显式降级吸收机制，闸门登记被回滚）——与参考闸门归因一致；测试先按直觉预期闸门报错，后按参考语义修正并记录。
3. **schema 校验**：本地 JSON Schema 子集校验器（不做类型强转，失败可恢复重试）；Pi 无原生 json_schema 属预期差异。

## 踩坑记录（已沉淀为测试模式）

- VM 域返回对象与宿主对象原型不同：`assert.deepEqual`（strict）失败，需 JSON 往返比较——后续跨域断言统一用此模式。
- 已 aborted 的 AbortSignal 不会重播 abort 事件：fake runner 需同步判干 `signal.aborted`。
