## 关键决策记录

1. **事件序号续接**：resume 同 runId 的事件序列从 lastEventSequence 续接（不回绕）——SSE 游标语义成立。
2. **闸门先于 completed**：run.completed 只在闸门/最少 agent 检查通过后发射；闸门失败发 run.failed。
3. **payload 脱敏返回副本**：sanitizePayload 返回 redactValue 后的副本（首版误返回原值，单测抓出）。
4. **engine 有界缓冲**：内存事件队列 500 条上限，慢消费者转持久层游标（readEventsSince）。
