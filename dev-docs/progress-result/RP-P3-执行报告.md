## 结论与 IR-010 建议

1. **关键词检索在当前工作负载下到 N=100 仍 100%**：召回@8 不衰减、针样本全命中。原因是注册项 keywords 词汇区分度高（用户话术与关键词字面重合），且 top-8 截断使提示词长度/延迟/tokens 随 N 平缓增长（4.1k→4.3k tokens）。
2. **朴素 BM25（CJK 一元分词）不占优**（92%）：一元切分放大常见字干扰且丢失子串匹配能力；若无中文分词器，BM25 升级无收益。
3. **all（不检索直喂全部）无准确率增益、tokens 上浮**：检索层的价值是成本控制而非常准确率（当前规模下）。
4. **建议（供 IR-010 / WX-P3 决策）**：
   - 现阶段**保持关键词检索**；把「keywords 与用户话术字面重合度」作为注册审核规范。
   - 触发升级的两个信号：① 注册表出现语义重叠工作流（同义词/跨语言表述增多，关键词召回开始掉）或 N>100；② 届时优先**带中文分词的 BM25**，语义检索（Embedding）在其后。
   - 成本主项是 LLM 调用本身（~4.2k tokens/次），检索升级不降单次成本，准确率不降级前不必投入。

## 局限（如实记录）

- 探针与干扰项关键词字面重合度较高（keyword 友好型负载）；语义改写型负载（如「帮我把这段英文变成中文」无「翻译」字样）未大规模铺设——RP-P1 样本库已有部分覆盖且 Prompt A 抽取正确。
- tokens 为路由调用单次口径，不含执行阶段。
