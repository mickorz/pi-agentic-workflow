## 关键决策

1. **磁盘事件格式不迁就 V2 契约**：V1 events.jsonl（`sequence`）保持不变，API 面经 toV2Event 映射（`seq`/checkpoint.approved|rejected/run.created）——CLI/Journal 兼容优先。
2. **等待态持久化在应用层**：engine 的 confirm 是内存通道；服务层在 checkpoint.requested/resolved 事件上同步 manifest waiting_checkpoint↔running（仅迁移非终态，不覆盖 completed）。
3. **跨进程审批**：持久记录 + resume 重问 version+1 + expectedVersion 防重复唤醒（内存通道仅同进程投递）。
