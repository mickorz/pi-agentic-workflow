## 4. 过程中发现并修复的真缺陷（跨阶段价值）

1. **失败 run 谎报 run.cancelled + checkpoint 拒绝后 manifest 被回翻 running**（P2-08，commit aebf975，详见 V2-P2 报告）。
2. **默认并发 `hardwareConcurrency-2` 在 3 核机器（CI macOS runner）=1**：parallel 串行化、race 挂死——DSL 契约（分支重叠）被小核数环境静默破坏。修复为 `max(2, cores-2)`+3 核模拟回归测试（commit e62983e）。
3. **Worker terminal 行在 Windows 管道被 process.exit 截断**：exit(0) 无终态→被误判异常退出。修复：write 回调冲刷确认后再退（sendFlushed），SIGTERM/finished 后不再立即 exit（e62983e）。
4. **resolveDefaultWorkerCommand 用 URL.pathname**：Windows 为 `/C:/...` 形式，existsSync 恒 false→Worker 启动即退→run 误判 interrupted。修复 fileURLToPath（95e408f）。
5. **test238 隐式依赖本机 Pi 凭证**：CI 无凭证超时。注入 fake runner（3b781a5）。
6. **checkpoint() 节点计入 result.agents**（agentCount 含伪 agent）：裁决不改 runtime（V1 result.json 形状兼容），web 用量面板展示层过滤 `kind==="checkpoint"`（aaa57ef）。
7. **【审计发现】checkpoint approve 后 Server 回翻 running 覆盖 Worker 终态（IPC 双写竞态，与 #3 同类）**：checkpoint 为最后节点时，Worker 在 approve 送达后立即写 completed，而 Server 侧 wireCheckpointRecording 的 waiting→running 回翻经 IPC 延迟晚落地把 completed 改回 running→manifest 卡 running、effectiveStatus=interrupted（真实完成的 run 被报为已中断）。b46a877 之前只修了 reject 分支，approve 分支仍存。修复（双层）：①run-store 终态不可逆守卫（TERMINAL_STATUSES 内不可迁出，迟到回翻静默丢弃 status；engine/CLI resume 传 force）；②withManifestLock 文件锁把 manifest 读-合-写变成跨进程原子（守卫的 read-check-write 在跨进程下不原子，锁内判定才成立；陈锁 4s 自愈，Atomics.wait 等待）；failRun 对已终态 manifest 不覆盖。回归：tests/unit/run-store-terminal-guard.test.ts 5 用例+worker-supervisor.test.ts「checkpoint 为最后节点」全栈用例（修复前在 IPC 延迟窗口下稳定复现 interrupted，修复后任意交错收敛 completed）+Playwright mock xss spec 8/8。复现装置 dev-examples/v2-web/cp-last-probe.mts。

## 5. 踩坑与经验索引

- Playwright `webServers`（复数）配置键被运行时静默忽略（TS 类型却放行）→ dev-docs/experience/playwright-webservers-plural-key-ignored.md
- 全角标点紧跟 `$VAR` 会并入变量名（unbound variable）→ perl 全量 `${VAR}`（fault-suite/demo 开发期两度踩）
- Playwright 选择器：`text=` 会匹配说明段落、reload 等 networkidle、hidden option 用 state:"attached"（gp2 五轮调试，固化进 gp2-browser.mts）
- vitest 默认 include 会吞 e2e/*.spec.ts → vite.config `test.exclude` 追加 `e2e/**`
- edit 工具多 edits 任一 oldText 不匹配整调用原子失败：修复未落地但被误记已完成，重跑才暴露——多 edit 后应立即 grep 验证
- CI 慢机时序断言：并行重叠窗口留足余量（150ms→500ms）+ NODE_TEST_CONCURRENCY=1 串行降载
