## 2. PRD 契约 vs 现状（逐项）

### 已满足（可作 P1 地基）
- **RunApplicationService**（src/application/run-service.ts:75）：get/cancel/resume/decideCheckpoint 齐全；错误码族 ServiceError（RUN_NOT_FOUND/RUN_STILL_ACTIVE/CONFLICT/RESUME_MISMATCH/SIDE_EFFECTS_UNACKNOWLEDGED/RUN_LIMIT_REACHED，run-service.ts:28-37）；并发上限 maxConcurrentRuns=2 缺省 + countActive()（run-service.ts:216-219）。
- **CheckpointService**（src/application/checkpoint-service.ts）：checkpoints.jsonl requested/decision 两行式持久化；version 自增（resume 重问，checkpoint-service.ts:96）；expectedVersion 冲突→CONFLICT、同决策幂等（applyDecision L115-145）；decisionBy 仅 local-user。
- **JSONL Event Store**（src/events/）：emitter seq 单调（resume 续接）、payload 脱敏+4KB 截断、jsonl-sink readEvents(runDir, afterSequence) 游标续读；engine.readEventsSince（engine.ts:226-228，"V2 SSE 续读面"）。
- **RunSnapshot**（src/engine.ts:58-67）：含 events.{count,lastSequence,sequenceValid} 游标。
- **V1→V2 事件映射** toV2Event（src/contracts/web.ts:80-101）：checkpoint.resolved→approved/rejected；StartRunInputV2{projectId,workflowPath} 类型已声明（web.ts:40-48，**run-service 未采用**）。
- **manifest**（src/persistence/run-store.ts:23-49）：status/pid/argsHash；isPidAlive；running+pid 死→interrupted 补偿（L115-136）。
- **设计基线**：docs/architecture/V2-runtime-server.md（IPC stdio JSON-lines、ready/heartbeat 5s/30s、取消顺序 IPC→10s→SIGTERM→3s→SIGKILL、Server 单写 events.jsonl）——纯文档零代码。
- 测试：run-service 7 / events 5 / checkpoint 7 / engine 5 / run-store 5 直接相关单测。

### 缺口（P1 要补）
1. **进程模型（P1-02 核心）**：runWorkflow 是同进程 async（src/runtime/workflow-runtime.ts:222）；engine active 为进程内 Map、checkpoint 等待=内存 resolver、cancel 仅本进程（engine.ts:219 无 active 即 throw）。无任何 Worker 子进程/IPC/heartbeat。
2. **HTTP/SSE 面全缺**：无 src/server/、无 fastify 依赖、无 web/ 前端、bin 无 web 命令。
3. **安全层全缺**：本地 token/Origin/CORS/Rate/Size/FORBIDDEN_PATH。
4. **契约小缺口**：start 无幂等键（StartRunOptions 无 idempotencyKey）；list 无分页过滤；WorkflowEventV1 缺 parentNodeId（层级在 payload.workflowScopePath/compositePath）；run.created 仅合成、run.interrupted 磁盘不产出；node.updated/node.cancelled 磁盘不产出。
5. **结构隐患**：src/cli/shared.ts executeWorkflowRun 与 RunApplicationService 双轨并存（PRD 允许兼容外壳，P1-07 CLI 兼容测试须覆盖）。
6. manifest 无 ownerInstanceId/startedAt（设计基线 §3.1 要求）。
