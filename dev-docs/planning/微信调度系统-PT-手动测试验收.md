## 3. 风险

- 真机微信的不稳定（风控/窗口限制）导致部分用例无法当场执行 → 允许以脚本化等效证据（FakeBot + 协议层记录）替代通信层证据，但**审批与安全负向用例必须真机**（涉及用户身份边界）。
- 缺陷修复引发回归 → 每个修复 commit 后必须重跑全量（沿用 T5 约定）。
