# publish.py --md-file 相对路径按 CWD 解析的坑

## 问题现象

G 阶段发布命令按 skill 模板传 `--md-file "<正文文件名>"`(相对文章目录的文件名),
在仓库根目录执行时报 `[FAIL] md not found: ThinkRail,…md`——文件明明就在文章目录里。

## 排查过程

`select_md()`(publish.py)对显式路径直接 `Path(explicit).is_file()`,
`Path` 相对**当前工作目录**解析;从仓库根跑时,文件名解析到仓库根下,自然找不到。

## 根因

历史调用恰好都在文章目录或传了绝对路径,坑一直没暴露;ThinkRail 篇首次在仓库根
以裸文件名传参触发。

## 解决方案

`select_md` 增加回退:显式路径不存在且非绝对路径时,先尝试 `article_dir / explicit`,
命中即返回;仍找不到才报错(2026-11-03 修复,draft_manager P0 Gate 46/46 回归通过)。

## 预防/注意事项

- 命令模板里 `--md-file <md>` 语义是"文章目录内的文件名或绝对路径",两种写法现在都安全
- 同类模式警觉:任何"相对路径"参数都要问一句"相对谁"——工具链里 CWD 经常是仓库根,
  而参数语义是相对文章目录
