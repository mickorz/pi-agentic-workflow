# 微信触发市场分析流程——可行性方案（2026-11-12）

> 需求：在公司等其他网络（屏蔽小红书等渠道）时，只需向微信 bot 发一条"分析目标"，流程在**本机（家庭 Mac）**自动启动并完成三渠道市场分析，结果落 Obsidian `60_Workspace/写作/市场分析/`。
> 结论：**可行**。全部基础设施已就绪，缺的只是一个新 workflow + registry 注册；两个真实依赖（本机常开 + Chrome 登录态开着）与降级方案见 §4。

## 1. 架构（信息流）

```
手机微信（任意网络：公司/户外）
  → 发「市场分析: <主题>」（或自然语言含触发词）
  → wechat-bot（本机 pm2 常驻，已稳定运行，渠道屏蔽不影响——微信本身不在屏蔽名单）
  → registry 关键词路由（同 videodigest-extract 先例）
  → market-analysis workflow（新，本机执行）
      ├─ 渠道采集：chrome-use（本机 Chrome 登录态）
      │    小红书=已登录直采 / 公众号=搜狗微信+分段拼链接 / 抖音=未登录可读
      ├─ 分析：content-intelligence 七步（步 7 确认门改为微信回执，不阻塞）
      └─ 报告落盘：60_Workspace/写作/市场分析/<YYYYMMDD>-<主题>.md（扁平命名，与灵感区新约定一致）
  → 微信回执（精简一句话式，同 videodigest 新回执风格）
```

关键点：**渠道屏蔽只影响你所在的网络，不影响本机**——采集全部发生在家里的 Mac 上，公司网络只承担微信消息收发。

## 2. 触发与交互设计

- **触发话术**（建议，注册 keywords ≥2 短词，WX-MOCK Gate B 纪律）：`市场分析` / `选题分析` + 主题。例：「市场分析: 企业知识库」「选题分析 AI 编程课」
- 可选平台定向：「市场分析: 企业知识库 只看小红书」（缺省三渠道按 30/30/30 配额）
- **时长预期**：样本 15-20 条 × chrome-use 逐页采集，约 10-30 分钟（比视频提取长一个量级）；task binding 异步跑，跑完微信回执
- **回执**（对齐 11-12 可读化定案）：
  - 受理回执：`📥 已受理市场分析：企业知识库（预计 15-25 分钟，完成后通知）`
  - 完成回执：`✅ 市场分析完成: 企业知识库（样本 18 条：小红书 7/公众号 6/抖音 5）→ 60_Workspace/写作/市场分析/20261113-企业知识库.md`
  - 失败回执：带一句原因（渠道全断/样本不足等）
- **确认门处理**：content-intelligence 第 7 步"人工确认"改为**非阻塞**——报告第 9 段确认清单照写，微信完成回执附三个待拍板项的一句话版；你在 Obsidian 看完报告后，回复「确认 方向一」或「重跑 只看公众号」即可驱动后续（进 gzh-article-craft 或重研究）。这符合 11-12 两确认点制的精神：agent 自主跑全流程，人只在决策点出现。

## 3. 产物与幂等

- 目录：`60_Workspace/写作/市场分析/`（已存在）；文件：`<YYYYMMDD>-<主题>.md`（扁平，同灵感区 11-12 新约定）
- 幂等：frontmatter 记 `analysis_key: <规范化主题>`，重发同主题 → 回执"已有报告+路径"，不重跑（想重跑说「重跑」）
- 报告结构沿用 content-research.md 九段；样本明细落 `content-intelligence/samples/<主题域>/`（现状约定不变）

## 4. 依赖与风险（真实约束）

| 依赖 | 现状 | 风险与对策 |
|---|---|---|
| 本机常开 + pm2 wechat-bot 存活 | 已验证（uptime 14 天级） | 停机/重启后消息丢失窗口小（微信服务器重连拉取）；pm2 开机自启已配 |
| **用户 Chrome 开着且小红书登录态有效** | 今日复测 ✓ | **最大依赖**。Chrome 关着 → 小红书不可采。降级矩阵：①Chrome 在 → 三渠道全采 ②Chrome 不在 → cdp-cli 自起实例可采公众号（搜狗）+抖音（免登录），**小红书跳过并在回执标注**「小红书未采（本机 Chrome 未开）」③cookie 过期 → 同上标注 |
| chrome-use relay 扩展在线 | 今日 ✓ | preflight 检查前置（同 F 阶段定案），失败即失败回执 |
| 搜狗/抖音反爬变化 | 今日实测通 | 已沉淀拼 URL 法；渠道单项失败不拖垮流程（content-intelligence D12 分级降级原则） |
| 长任务中断 | — | 断点续跑 v1 不做；失败重发「重跑」即可（采样无副作用） |
