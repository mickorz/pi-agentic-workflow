## 三、改进指向（修正后重新分派）

1. **文字问题 → T4 维持现状**：expected_text 闭环是通用质量机制（声明→生成→人工审核→失效），
   不依赖初版根因结论，实现保留。“零字验收 vs 指定字验收”的翻转叙述降级为“待真机重取证据后定”，
   但日报卡点 2（用户手动使用经验：要求带字缺字）仍直接支持“指定字 + 人工审核”方向。
2. **模型遵循度（初版模式 1/2 想回答的问题）→ 需重取**：用执行器真机跑批（preview + 少量 batch），
   prompt 可控、产物与 manifest 对应关系确定，再判“负向约束遵循度/构图劫持”是否真实存在。
3. **证据链断裂 → T3（已落地部分够用）**：本次修正反而补充了新场景——“跑批产物被手动删除/替换”，
   建议 T3 后续任务（重命名解绑）一并覆盖“检测到 succeeded 条目文件缺失时显式提示该图已被替换”。
4. **样例量边界不变**：任何结论需可控样本。
