## Workflow Execution Intelligence（新增独立执行分析能力）

四层结构：Workflow 执行（记录阶段/Skill/工具事件）→ 执行数据（耗时/Token/工具调用/错误）→ 交互数据（审批/等待/修改/拒绝）→ 执行分析与评测（瓶颈/成功率/返工率/质量）→ Workflow 优化建议（审批策略/Skill/工具/缓存/执行顺序）。

**四种时间必须区分**（否则分不清 Agent 慢、工具慢还是协作流程慢）：

- `execution_time`：Agent 实际执行
- `approval_wait_time`：等待人工审批
- `tool_wait_time`：等待外部工具/服务
- `human_work_time`：人工实际操作

## 待补效率指标（当前报告只有耗时，缺效率维度）

- 每篇文章耗时趋势 / 各 Skill 执行耗时 / 每次审批平均耗时 / 每次交互的必要性
- Humanizer：扫描字数、Token、缓存命中率
- 生图：单图生成成功率
- 发布：发布成功率、失败重试次数
- 质量：压缩到 60 分钟后文章质量是否下降——**不能为速度牺牲质量**
