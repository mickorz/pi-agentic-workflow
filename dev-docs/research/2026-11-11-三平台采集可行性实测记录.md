# P0.1-T2 三平台采集可行性实测记录

> 方法：chrome-use（用户登录态真实 Chrome）+ web_search_prime + web_reader，逐路径验证
> 目的：验证公众号/小红书/抖音的可获取字段、采集成本、失败原因——先验证能力，再定自动化方案（P0.1-D13）

## 二、逐平台实测过程与证据

### 2.1 微信公众号

- **发现渠道实测**：web_search_prime 以 `mp.weixin.qq.com/s + 关键词` 多轮搜索，仅命中 2 条无摘要直链；36kr 等转载文（「本文来自微信公众号湘江数评」）是间接发现渠道。搜狗微信结果页 URL 含 `&` 参数被 web_reader 拒绝，且历史上反爬严格。
- **抓取实测**：web_reader 直接抓文章 → 触发风控（「环境异常，完成验证」）；**chrome-use（真实登录态 Chrome）打开 → 完全正常**，eval 提取全字段成功：
  - 样本①：《小红书混合云架构下自用数据中心设计实践与探索》/ 小红书技术REDtech / 2025-12-25 / 正文 6348 字
  - 样本②：《我们发现企业AI治理真正难的，不是"禁"，而是"放"》/ 一通信息 / 2026-04-22 / 正文 5687 字（**正好同主题**）
- **指标实测（关键负结论）**：滚动到底部 + eval 检查 `#js_read_area`/bottom_bar → **bar 存在但无任何数字**（只有 赞/分享/推荐/写留言 按钮）。PC 登录态当前版本不展示阅读量；点「赞」可获数字但会污染用户账号互动，**禁止**。→ 公众号样本指标一律 `N/A 平台不公开`，tier 无法数据化判定（unknown），与 skill 纪律一致。

### 2.2 小红书

- **发现渠道实测**：web_search_prime 搜 `xiaohongshu.com/explore + 关键词` → 无任何具体笔记直链（仅平台首页）。
- **站内实测**：chrome-use 打开搜索页 `xiaohongshu.com/search_result?keyword=企业知识库` → **登录墙**（「登录后查看搜索结果」，noteCount=0）。
- **登录态实测（用户确认）**：公司网络将小红书登录列入黑名单，登录不可用 → 自动/半自动路径全部阻断。
- **结论**：小红书研究走**人工导入模式**——用户手机端看到相关笔记时保存链接/截图/评论区原话，交给 agent 按统一样本 Schema 分析。Skill 流程设计中该平台步骤默认人工介入，不阻塞流程（D12）。

### 2.3 抖音

- **发现渠道实测（超预期）**：web_search_prime 搜 `douyin.com/video + 关键词` → 收录良好，**搜索摘要直接带发布日期、账号名、赞数快照**：
  - 《自研还是买产品？一句话帮你选》#企业知识库 — 1052 赞（2026-10-28，纳服科技）
  - MaxKB 手册变问答助手 — 2784 赞（2026-11-02，Stellink）
  - dify知识库 — 8955 赞（2025-02-13，AI大聪明）
  - **《基于RAGFlow+DeepSeek构建企业级知识库》— 3.5万赞（2025-02-14，数致西瓜讲AI）← 同选题爆款级数据点**
- **单视频页实测**：chrome-use 未登录直开 → **全字段可读**：文案、时长（27:39 口播长视频）、互动数列表（914/151/1230/307/1.1万/3.5万/1582——点赞 3.5 万与搜索摘要互证）。无需登录，无风控。
- **适配器增强（登录态可用时）**：chrome-use 自带 `douyin/search`（站内搜索）与 `douyin/user-videos`（含评论区抓取）；creator 系列适配器（stats/drafts/publish）属 P2 自己账号数据，不在市场研究范围。
- **内容形态洞察（首条）**：同选题最高赞样本是 **27 分钟深度口播教程**而非短平快——【待验证假设】抖音企业向内容的长视频深度形态可能被低估。

## 四、局限

- 公众号候选发现仍依赖搜索引擎间接收录，覆盖率未知；微信搜一搜的人工导出流程未实测（需用户手机配合，留待 P0.1-T4 正式研究时执行）
- 抖音评论区未实测（登录态被 daemon 断连打断；`douyin/user-videos` 的 with_comments 能力留待登录态恢复后验证）
- 小红书零验证（黑名单硬阻断）；其「赞藏比/评论区痛点」分析规范暂为纸面设计，待人工导入首批样本后校准
- 抖音互动数列表（914/151/1230…）与按钮的精确映射（赞/评论/收藏/分享）未逐项确认，正式采样时需人工核一次
