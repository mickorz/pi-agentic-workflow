# 平台分析规范（platform-profiles）

> 每个目标发布平台一套分析规则。六维拆解（标题/开头/结构/价值/传播/差异化）保留，但**比较基准、指标语义、迁移规则按平台差异化**。
> 研究资源权重（2026-11-12 用户定案：三平台均等）：小红书 30% / 公众号 30% / 抖音 30% / 其他 10%——权重是资源配置，不是证据可信度评分。

## 通用纪律（三平台共同）

1. **平台内比较**：爆款 vs 普通只能在对照组内判定——控制变量：平台、内容格式、发布时间、账号规模、选题（comparison_group 字段落地，见 templates.md）
2. **跨平台只迁移机制，不迁移表现结论**：A 平台的痛点线索/标题句式/结构思路可参考；A 平台的表现数字不能预测 B 平台的表现
3. 报告结论**按目标发布平台生成**：「我准备写公众号文章」→ 主研究公众号，其他平台只提供痛点线索与表达机制

## 小红书（权重 30%，痛点与收藏型表达）

| 项 | 规范 |
|---|---|
| 优先采集 | 图文笔记、站内搜索结果、评论区、热门笔记 |
| 核心分析维度 | 封面（首图钩子）、标题（字数/痛点句式）、点赞收藏比（收藏>点赞=工具价值）、评论区的真实痛点原话 |
| 指标语义 | 赞藏比是核心：高收藏低点赞=工具型内容；评论区原话=需求一手证据（引用要注明「评论区观察」） |
| 发现渠道（2026-11-12 复测） | **用户 Chrome 已登录，chrome-use 优先采集**（explore/feed/笔记/评论实测可读，推翻旧「网络黑名单/纯人工导入」结论）；人工导入作兜底。增强选项：xiaohongshu-mcp 子模块已 build 可用（Go 服务 :18060），但需独立扫码登录一次才可调 API，暂不启用 |
| 对照组要求 | 同为图文笔记（图文 vs 视频笔记不可比）；同赛道话题 |

## 微信公众号（权重 30%，长文主阵地）

| 项 | 规范 |
|---|---|
| 优先采集 | 同赛道文章、同行账号、爆款与普通文章配对 |
| 核心分析维度 | 标题（GEO/数字/身份）、开头（前 3 段留人）、长文结构（章节组织）、分享/在看机制、阅读与关注转化 |
| 指标语义 | 阅读量=触达；在看/分享=社交认可（强信号）；收藏≈价值判断。**多数不可得**（仅 10w+ 档），默认 C 级预期 |
| 发现渠道（2026-11-12 实测更新） | ①**搜狗微信在真实 Chrome 可用**（无验证码、结果 10 条/页；旧「被拒」结论仅适用于抓取工具）——跳转链接是分段拼 URL 防抓，eval 抓 `/link` 页拼 `url += '…'` 片段后可直达文章 ②通用搜索对 mp.weixin.qq.com 收录极差 ③微信搜一搜需 App 内人工——半自动模式：人工导出候选，chrome-use 打开分析 |
| 指标实测 | **PC 登录态不展示阅读数**（bottom_bar 仅按钮无数字，实测确认）→ 指标一律 `N/A 平台不公开`，tier 判 unknown；禁止点赞/在看换取数字（污染账号互动） |
| 对照组要求 | 同为公众号长文；发布时间相近；账号量级相近（百万粉与百粉不可比） |

## 抖音（权重 30%，表达机制来源）

| 项 | 规范 |
|---|---|
| 优先采集 | 口播视频、知识类短视频、评论区 |
| 核心分析维度 | 前 3 秒钩子（开场句式）、叙事结构（悬念/反转/清单）、点赞/评论/分享、完播表现（若可得） |
| 指标语义 | 播放/完播=注意力留存；评论=争议与共鸣点。**对长文只有机制参考价值** |
| 发现渠道（2026-11-11 实测） | **三平台中唯一可自动化**：①通用搜索收录良好且摘要自带发布日期/账号/赞数快照 ②未登录单视频页全字段可读（文案/时长/互动数，双源互证）③登录态适配器 douyin/search + user-videos（含评论区）可增强 |
| 对照组要求 | 同为口播知识类；时长相近（60s 与 3min 不可比） |

## 其他渠道（权重 10%，事实与技术素材）

知乎/CSDN/技术博客/厂商博客/英文博客：**降级为素材来源**——技术细节、研究数据、案例线索的取材地，不再作为「什么内容有效」的表现判断来源。其样本登记照常（证据分级/指标纪律不变），但六维拆解的「表现结论」不再从这些渠道得出。

## 与首轮实测（2026-11-11）的衔接

首轮 23 条样本全部落在「其他渠道」权重档（10%），其研究报告的定位随之修正：**该报告是素材与技术侧研究，不构成公众号表现策略的依据**；其第 7 段内容方向的「标题策略」部分仅可作起点。公众号/小红书/抖音三平台研究在 P0.1-T2 实测后由 P0.1-T4 补齐。
