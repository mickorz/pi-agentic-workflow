# content-intelligence — 内容研究数据资产目录

> 本目录是**资产层**：存放 Content Intelligence 流程产出的市场样本、研究报告与模式库。
> 规范层在 `.pi/skills/content-intelligence/`（SKILL.md 教流程，本目录存产出），两者不混放。
> 全部为公开市场信息的分析记录，随 git 提交。

## 目录职责

| 子目录 | 职责 | 产出时机 |
|---|---|---|
| `samples/` | 市场样本记录，按主题域分子目录 | 每次选题研究时登记 |
| `research/` | content-research.md 研究报告（一次研究一份） | 每次选题研究产出 |
| `patterns/` | 标题/开头/结构模式库，**只从真实样本分析回填，禁止预填** | 研究积累后提炼 |
| `analytics/` | 自己公众号的发布表现数据（P2 预留） | P2 启动后 |

纪律：`samples/`（公开市场样本）与 `analytics/`（自己公众号数据）严格分开——前者研究市场，后者才是检验自己内容策略的真实依据。

## 样本登记规则速查

1. 每条样本一份 YAML 记录（模板见 `.pi/skills/content-intelligence/references/templates.md`）
2. **来源与采集日期必填**：原始链接 + 平台 + 作者 + 采集日期，缺一不收
3. **指标三值规则**：views/likes/comments/favorites/shares 每项只能是——真实数字（注明采集日期）/ `N/A 平台不公开` / `未采集（附原因）`；**禁止编造**，宁空勿编
4. **表现分层要数据依据**：tier 判定必须基于同平台、同主题/相近主题样本的相对比较，并在 `basis` 记录判定基准；不足以比较时标 `unknown`，不强迫归类
5. **证据等级逐条标注**：A（完整正文+表现数据）/ B（正文+标题，数据不全）/ C（仅标题摘要）
6. **不只收爆款**：每 ≥5 条爆款至少配 1 条同平台同主题的普通表现样本
7. **跨格式标注**：`content_format` 必填；短视频/图文样本可作灵感来源，不作公众号文章表现基准
8. **转载去重**：同一篇内容多渠道转载按原始出处计一条，转载链接并入备注
