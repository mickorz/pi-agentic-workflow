# research/ — 选题研究报告

每次 Content Intelligence 选题研究产出一份 `content-research.md`，命名 `YYYY-MM-DD-<主题>.md`。

报告模板：`.pi/skills/content-intelligence/references/templates.md`。

纪律：

- 报告是**人工确认门之前的最后一环**：报告产出后必须经用户确认选题方向/内容类型/标题策略，才进入 gzh-article-craft 创作流程
- 报告不含文章正文的任何章节
- 样本不足、证据等级过低（A 级样本占比过低）必须在报告内声明，不得掩饰
