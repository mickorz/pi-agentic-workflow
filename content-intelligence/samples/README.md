# samples/ — 市场样本库

按主题域建子目录，命名用小写英文+连字符。首批约定主题域（按需新建，不预设空目录）：

- `ai-agent/` — Agent、Agentic Engineering 相关样本
- `ai-tools/` — AI 工具盘点、测评类样本
- `enterprise-ai/` — 企业 AI 落地、知识库、数据相关样本
- `programming/` — 程序员工作方式、AI Coding 相关样本

一条样本一个 `.md` 文件（YAML 记录 + 简要分析），命名 `<采集日期>-<平台>-<主题关键词>.md`。

登记规则见上级 `README.md`；模板见 `.pi/skills/content-intelligence/references/templates.md`。

纪律重申：

- 样本不足时在研究报告中明确报告数量与原因，**禁止为凑数降低质量或收录不相关内容**
- 表现分层（tier）必须有同平台同主题的相对比较依据，否则 `unknown`
- 普通表现样本同样要收（每 ≥5 条爆款配 ≥1 条普通对照）
