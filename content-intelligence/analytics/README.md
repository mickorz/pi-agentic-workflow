# analytics/ — 自己公众号发布表现数据（P2 预留）

本目录在 P2 阶段启用，用于记录**自己公众号**的历史发布表现（阅读、转发、推荐、收藏、在看等）。

P0/P1 阶段保持为空。

两条边界纪律：

1. **与市场样本分开**：`samples/` 是别人的公开内容（研究市场），本目录是自己的真实数据（检验策略）——两者不可混放、不可互相替代结论依据。
2. **数据来源**：公众号后台导出/人工记录为准；后台不可得的指标留空，禁止估算补齐。

预期形态（P2 再细化）：`published-content-performance.json` 或按篇登记的 md，字段至少含：标题、发布日期、内容类型（八类）、标题策略、阅读/转发/推荐/收藏、目标读者是否命中。
