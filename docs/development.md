# Development

Contributor guide for this research repo. Chinese version: [zh-CN/development.md](zh-CN/development.md)

## Repository Conventions

- Reader-facing docs live in `docs/` and are committed (English + zh-CN, same filenames and structure).
- Working-process docs (designs, research, plans, progress) live in `dev-docs/` and are NOT committed.
- Experiments and scratch output go to `dev-examples/` (not committed).
- Full rules: [CLAUDE.md](../CLAUDE.md)

## Research Workflow

1. Record findings, comparisons, and ideas in `dev-docs/research/`.
2. Designs ready to act on move to `dev-docs/design/`.
3. Milestones are tracked in `dev-docs/progress/` and `dev-docs/progress-result/` (one report file per stage).
4. Pitfalls and solutions are captured in `dev-docs/experience/`.

## Commit Style

Short imperative subject lines; group related files in one commit.
