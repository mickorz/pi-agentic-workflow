# 图片类型规则：数据图（data-chart）

> 层级：类型级。Compiler 提取 `prompt-block` 拼进所有 data-chart 条目的 `items[].prompt`。
> 修改本文件 = 仅 data-chart 条目失效重编译，其他类型不受影响；风格审批不受影响。
> 编译映射：type `data-chart` → D6 `kind: body`。
> 边界声明：本类型优先走确定性本地渲染（P2 T18），仅在数据简单且必须文生图时使用；图内数据必须来自 source_facts 提供的真实数据。

## prompt-block

数据图构图：图表类型与数据形态匹配——比例用条形或饼图，趋势用折线，对比用分组条形；一种图表只表达一组关系。

数据忠实：图中数值、比例、趋势必须与给定数据完全一致，禁止估算、禁止编造、禁止美化夸大差异。

可读性：坐标轴与刻度清晰，数据标签字号大、位置不遮挡图形主体；无三维效果、无渐变装饰、无网纹底。

图表之外不添加任何装饰性插画元素，画面即图表。

## checklist

- [ ] 数值与 source_facts 完全一致（逐个核对）
- [ ] 图表类型与数据形态匹配
- [ ] 无三维、无渐变、无装饰插画
- [ ] （P2 起优先本地渲染，本类型调用付费 API 需在计划审核时给出理由）
