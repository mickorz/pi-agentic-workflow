# 图片类型规则：封面（cover）

> 层级：类型级。Compiler 提取 `prompt-block` 拼进所有 cover 条目的 `items[].prompt`。
> 修改本文件 = 仅 cover 条目失效重编译，插画/信息图/数据图不受影响；风格审批不受影响。
> 编译映射：type `cover` → D6 `kind: cover`。

## prompt-block

封面构图：核心视觉主体唯一且突出，置于画面视觉重心；主体轮廓清晰，缩小到缩略图尺寸仍可辨认。

标题安全区：画面一侧预留大面积留白区域，不放置任何关键元素和细节，供后期排版标题使用。

缩略图可读性：以大色块和强轮廓为主，避免细碎纹理和小元素；远看有明确形状对比。

封面不呈现流程、数据或段落式信息，只承担第一眼吸引力。

## checklist

- [ ] 缩略图尺寸下主体一眼可辨
- [ ] 安全区干净，后期可叠标题
- [ ] 主体唯一，不贪多
