# dev-examples/ —— 开发期沙盒

> **不对读者负责**：这里存放开发中的脚本试验、联调配置与临时输出。
> 任何东西都可能随时失效、重构或删除；不要把这里的目录当作文档引用。

## 约定

1. **一个开发主题一个子目录**，kebab-case 命名（如 `feature-x-e2e/`）。
2. 子目录内自便：试验脚本、联调配置、断言脚本、输出文件都行；
   运行产物（日志、临时输出、node_modules 等）一律 gitignore，**不提交**。
3. 这里**不维护索引**——目录本身就是过程产物，完成即删。
4. 验证通过的内容毕业进正式代码与读者向文档（`docs/`），然后删除这里的对应目录。
